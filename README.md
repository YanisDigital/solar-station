# VOLTARIA — лендинг сонячних станцій

**🔗 Живий сайт: [solar-station.yanis-ua.workers.dev](https://solar-station.yanis-ua.workers.dev/)**

Демонстраційний портфоліо-кейс: односторінковий лендинг з продажу та монтажу
сонячних станцій для приватних будинків у передмісті Києва.

> **VOLTARIA — вигадана компанія.** Сайт створено виключно як приклад роботи.
> Телефон, пошта, соцмережі та форма заявки не працюють — будь-який клік по них
> відкриває пояснювальне вікно. Ціни, відгуки та статистика ілюстративні.

## Що всередині

| | |
|---|---|
| **Стек** | Чистий HTML + CSS + JavaScript. Без збірки, без залежностей, без фреймворків. |
| **Мови** | Українська (за замовчуванням) та англійська, перемикання без перезавантаження. |
| **Розмір** | ~140 КБ коду + ~160 КБ шрифтів + ~1,2 МБ фото (усі — нижче першого екрана, з `loading="lazy"`). |
| **Підтримка** | Усі сучасні браузери. Без polyfill-ів, graceful degradation без JS. |

### Ключові рішення

**Hero на чотирьох шарах параллаксу.** Небо, селище з будинком, передній план
і текстовий шар рухаються з різною швидкістю: один цикл `requestAnimationFrame`,
тільки `transform`, пасивні слухачі, пауза коли секція поза екраном.
Шари намальовані в SVG, а не зібрані з фотографій — растрове фото неможливо
розкласти на прозорі шари.

**Інтерактив «Blackout».** Головна ідея сторінки: натисніть кнопку під сценою
(або будь-де на сцені мишею) — у селищі гасне світло, а будинок із станцією
продовжує світитися. Біль і обіцянка показані одним жестом, без жодного слайда
«переваги». На мобільних це основний елемент взаємодії, тому керування винесено
в окрему кнопку — текст героя займає майже весь екран і не годиться як ціль тапу.

**Калькулятор окупності.** Два повзунки, арифметика на клієнті, жодних форм.
Припущення винесені в коментар у коді: тариф 4,32 ₴/кВт·год, вироблення
1050 кВт·год на 1 кВт встановленої потужності за рік, 5 м² даху на 1 кВт,
курс 45 ₴/€. Результат навмисне чесний — окупність виходить 10–13 років, і саме
ці цифри повторює блок FAQ. Сторінка ніде не суперечить сама собі.

**Доступність.** Семантична розмітка, одна `h1`, `aria` на акордеоні, слайдері
та модальному вікні, фокус-пастка й повернення фокуса, керування з клавіатури,
видимий фокус, контраст AA. `prefers-reduced-motion` вимикає параллакс і всі
анімації, залишаючи сторінку повністю робочою.

**Стійкість до зупиненого рендера.** Акордеон анімується через примусовий
reflow, а не `requestAnimationFrame`, і завершується за `transitionend` **або**
за таймаутом. Слайдер перевіряє, чи `scroll-behavior: smooth` реально спрацював,
і за потреби переходить стрибком. У фоновій вкладці, де браузер не малює кадри,
обидва компоненти працюють, а не зависають напіввідкритими.

## Структура

```
index.html                 розмітка, inline-SVG сцени, JSON-LD
assets/css/style.css       токени, секції, адаптив, reduced-motion, print
assets/js/i18n.js          словник UA/EN + застосування перекладів
assets/js/parallax.js      шари героя та перемикання день/ніч
assets/js/app.js           калькулятор, слайдер, акордеон, модалка, форма
assets/img/cases/          фото об'єктів
assets/css/fonts.css       @font-face на локальні шрифти
assets/fonts/              Unbounded, Manrope, JetBrains Mono (woff2)
robots.txt · sitemap.xml · site.webmanifest
```

### Як додати переклад рядка

1. У розмітці: `data-i18n="ключ"` для тексту або
   `data-i18n-attr="alt:ключ;placeholder:інший.ключ"` для атрибутів.
2. У `assets/js/i18n.js` додати ключ в обидва словники, `ua` та `en`.

Відсутній ключ не ламає сторінку: `t()` повертає український варіант, а якщо
немає і його — сам ключ, тож пропуск одразу видно.

## Запуск

Файли статичні, тому достатньо будь-якого сервера:

```bash
python -m http.server 5173
```

Потім відкрийте `http://localhost:5173`. Подвійний клік по `index.html` теж
працює — шрифти самостійно розміщені, тому `file://` їх не блокує.

Мову можна задати посиланням: `?lang=en`.

`python -m http.server` не читає `_headers`, тож локально сторінка відкриється
без CSP та інших заголовків безпеки — це нормально, вони застосовуються лише
на Cloudflare. Перевіряти їх варто вже на живому деплої (`curl -I <URL>`).

## Деплой на Cloudflare Workers

Сайт статичний, тому деплоїться як Workers static assets — код воркера
відсутній. Запити до статики на безкоштовному тарифі не тарифікуються й не
мають ліміту.

**Налаштування в дашборді:** Workers & Pages → Create application → Import a
repository → цей репозиторій.

| Поле | Значення |
|---|---|
| Project name | `solar-station` (мусить збігатися з `name` у `wrangler.jsonc`) |
| Build command | `rm -rf dist && mkdir dist && cp -r index.html robots.txt sitemap.xml site.webmanifest assets _headers dist/` |
| Deploy command | `npx wrangler deploy` |

Публікується **не корінь репозиторію, а `dist/`**. Це свідомо: так на CDN
гарантовано не потрапляють `.git`, `README.md`, `LICENSE` і сам
`wrangler.jsonc`. Перевірити локально тим самим рядком, що й на сервері:

```bash
rm -rf dist && mkdir dist && cp -r index.html robots.txt sitemap.xml site.webmanifest assets _headers dist/
```

### Навіщо `_headers`

`_headers` — єдине джерело політики безпеки сайту: `index.html` не містить
дубля в `<meta http-equiv="Content-Security-Policy">`, тому вони не можуть
розійтися. GitHub Pages, на якому раніше жив демо-деплой, узагалі не вміє
віддавати власні заголовки відповіді — політику доводилось дублювати в
`<meta>`, а такий варіант не може виразити `frame-ancestors` чи
`X-Frame-Options`, тобто не захищає від clickjacking. На Cloudflare це
закрито: `frame-ancestors 'none'` + `X-Frame-Options: DENY` у справжніх HTTP-
заголовках. Плюс довгий кеш для шрифтів замість дефолтних 10 хвилин.

## SEO

- `title` і `description` під запит «сонячні панелі під ключ Київська область»,
  обидва перекладаються разом із мовою;

Перевірити розмітку: скопіюйте вміст `index.html` у
[Rich Results Test](https://search.google.com/test/rich-results).

## Приватність і безпека

Усі контактні дані навмисно неможливі, а не просто вигадані: домен у зоні
`.example` (зарезервована IANA, її не можна зареєструвати), номер `+380 44 000
00 00` не видається абонентам, адреса — «вул. Прикладна». Так демо-сайт не
може випадково направити трафік чи дзвінки на реальну людину.

Чого в розмітці свідомо **немає**:

- `aggregateRating` — вигаданий рейтинг у структурованих даних Google трактує
  як спам, а санкції прилітають на домен, де сайт опубліковано;
- `geo` з координатами — вигаданій компанії не потрібна точка на карті, а
  точні координати вказують на реальне місце.

Поля форми **не мають атрибута `name`**. Це навмисно: форма нічого не надсилає,
але якщо в користувача вимкнено JavaScript, звичайний submit відправив би GET і
поклав би номер телефону в URL, історію браузера та заголовок `Referer`.
Без `name` в адресу не потрапляє нічого.

Параметр `?lang=` перевіряється через `hasOwnProperty`, а не просто
`DICT[value]`: інакше `?lang=constructor` пройшов би перевірку й записав
успадковане значення в `<html lang>` і в `localStorage`.

У `localStorage` зберігається єдиний ключ — `voltaria.lang` з обраною мовою.
Жодних персональних даних, аналітики, трекерів чи cookie на сайті немає.

Політика безпеки живе в справжніх HTTP-заголовках (`_headers`, деталі — у
розділі «Деплой на Cloudflare Workers» вище), а не в `<meta>`. Усе, крім двох
`data:`-фонів у CSS і одного вбудованого скрипта (дозволений за хешем, а не
через `unsafe-inline`), обмежене власним походженням. `form-action 'none'`
стоїть свідомо: демо-форма не повинна відправлятися нікуди навіть без JS.
`frame-ancestors 'none'` і `X-Frame-Options: DENY` закривають clickjacking —
на GitHub Pages, де сайт жив раніше, це було неможливо в принципі.

Сторінка не робить жодного стороннього мережевого запиту: шрифти самостійно
розміщені в `assets/fonts/` (див. розділ «Шрифти» нижче) замість завантаження
з `fonts.googleapis.com`, яке передавало б Google IP-адресу й User-Agent
кожного відвідувача.

Аватари у відгуках — не фотографії, а ініціали (див. розділ «Зображення»):
стокове фото реальної людини поруч із вигаданою цитатою — непотрібний ризик
для чужих прав на зображення.

## Перед використанням як шаблону

1. Замініть домен у `canonical`, `hreflang`, `og:url`, `sitemap.xml`,
   `robots.txt` і JSON-LD — зараз там адреса демо-деплою на GitHub Pages.
2. Підставте справжні телефон, пошту й адресу — у футері, в `tel:`-посиланні
   та в JSON-LD.
3. Приберіть блок-дисклеймер у футері, плашки «відгуки вигадані» / «цифри
   ілюстративні» та перехоплення контактів у `app.js`.
4. Поверніть полям форми атрибути `name` і задайте формі реальний
   `action`/`method` — інакше дані не дійдуть на сервер. **І не забудьте
   послабити `form-action 'none'` у CSP** — інакше браузер мовчки
   заблокує відправку.
5. `aggregateRating` додавайте лише тоді, коли за ним стоять справжні відгуки.

## Шрифти

[Unbounded](https://fonts.google.com/specimen/Unbounded) (заголовки),
[Manrope](https://fonts.google.com/specimen/Manrope) (текст),
[JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono) (цифри) —
усі під Open Font License, самостійно розміщені в `assets/fonts/` (не
завантажуються з Google Fonts).

Кожна родина ділиться на два `.woff2`-файли — `*-latin.woff2` і
`*-cyrillic.woff2` (кирилиця покриває українські літери і/ї/є/ґ). Це той
самий варіативний файл, що віддає й сам Google: один файл на підмножину
символів обслуговує всі накреслення (400/600/800 для Unbounded,
400/500/700 для Manrope, 400/700 для JetBrains Mono) — тому файлів лише 6,
а не 16.

Це навмисне рішення про приватність: єдиний зовнішній запит, який лишався
на сторінці, — до `fonts.googleapis.com`/`fonts.gstatic.com`, і він передавав
Google IP-адресу й User-Agent кожного відвідувача сторінки. Тепер сторінка
не робить жодного стороннього мережевого запиту.
